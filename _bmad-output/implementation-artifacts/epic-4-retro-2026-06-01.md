## What Went Well

1. **"Seam-as-contract" paid forward.** Story 4.2's `Transport`/`TransportResponse` seam + conditional import were designed in *anticipation* of 4.10's web implementation. By 4.10 the entire web transport was constraint-solving: fill one stub file (`web_transport.dart`), return the right shape, and every layer above (auth, retry, chunk synthesis, lifecycle hooks, `abortOnCancel` <50 ms) worked on web for free. 4.10 — the widest footprint — drew **0 review patches**.

2. **Adversarial review caught real, execution-verified defects — never speculation** (memory: *"Confirmed" needs adversarial evidence*):
   - **4.1** — empty `data:` frame crash (`jsonDecode("")` → `ProtocolError` out of `async*`); truncated UTF-8 at EOF leaking a bare `FormatException` (fixed via `const Utf8Decoder(allowMalformed: true)`); dead BOM-strip code removed (verified `utf8.decode([0xEF,0xBB,0xBF]).length == 0`).
   - **4.2** — `package:http`'s `IOClient` wraps `SocketException` in `_ClientSocketException` (verified against http 1.6.0 source); the exact-name classifier missed it → fixed with `TransportErrorClassifier` (real `is SocketException`) behind the io seam. Plus a socket leak on non-2xx (drain-before-throw).
   - **4.7** — PII redaction `_scrub` had three live-verified sharp edges (empty-match `RegExp` injecting between every char; later patterns re-matching inside `[REDACTED]`; order-dependent overlaps) — **all would silently leak PII in production**. Rewritten to single-pass `Pattern.allMatches` with span coalescing. Empty `patterns` upgraded from `assert` (stripped in AOT) to `throw ArgumentError.value`.
   - **4.9** — untested `onError` arm (mid-stream error → `onDisconnect(cause)` + forward) was load-bearing; added `_idleServer` test.

3. **"Reuse > reinvent" validated by outcome data** (CLAUDE.md *no vestigial code*). 4.8 re-exported koel_core's property-tested `chunksStage` instead of duplicating ~120 LOC of envelope-tracking state — and *proved* the transport-synthesis + pipeline-synthesis composition is idempotent. 4.9 stayed a passive closure fan-out (no logging, no deps). Stories that reused (4.8, 4.10) had the cleanest outcomes and fewest gotchas.

4. **Trap-based story specs prevented re-litigation and reinvention.** Every story doc explained *why* the spec was worded so precisely: error contract is value-not-throw (4.1); cancel propagates for free through the existing chain (4.3); interceptors transform `input`, not requests (4.5); synthesis must live beneath retry + inside abort (4.8); hooks fire per-connection from the terminal so retry re-fires them (4.9). This matured "AC-vs-reality mapping" (Epic 2/3) into a documented decision record per story.

5. **Absolute scope discipline (mirrors Epic 2/3).** Finalization gates (member-doc `analysis_options.yaml` + ≥90% coverage) were deliberately deferred 4.1–4.9 → concentrated into the 4.10 sealer. The barrel grew exactly the right exports in order. Epic 3 AI#2 (`tool/coverage.sh packages/koel_http 90 90 with_chrome`) shipped in the root `test:coverage` script.

## Challenges & Patterns

### Challenge 1 — "Dropped ctor param" recurring bug (3 occurrences)
The 4.2 constructor accepted `synthesizeChunks` / `onConnect` / `onDisconnect` but the initializer list **never stored** them (consumed in later stories). The *identical* bug surfaced again in 4.8 (`synthesizeChunks`) and 4.9 (`onConnect`/`onDisconnect`). One bug class, three stories. Root: a ctor that accepts forward-looking params before the consuming story wires them is a latent "accepted-but-dropped" trap that the analyzer cannot catch (no dead-field warning when the param is "used" by the ctor signature). → **Action Item #2.**

### Challenge 2 — Interceptors have no direct path to HTTP request headers
`_TransportTerminal` hard-codes headers, so every header-touching interceptor must **transform `input`**. 4.5 resolved this with the `forwardedProps[AuthInterceptor.transportHeadersKey]` reserved-key seam — resolved headers ride on `RunAgentInput`, and the terminal **strips the key before `encodeRunAgentInput`** so a Bearer token never leaks onto the wire, with protocol headers (`Content-Type`/`Accept`) merged **last** so auth can't clobber them. Clean, but the seam was non-obvious and is the contract Epic 5's adapters inherit.

### Challenge 3 — `abortOnCancel` deliberately strands cancel → second-controller pattern
Because `SseParser.parse` is `async*` + `await for`, cancel is stranded (relying on it threading through blows the 50 ms budget). 4.3 fires `response.abort()` immediately on consumer cancel. But any code needing to *observe* the cancel (4.6 FINE drop log, 4.9 `onDisconnect(null)`) had to wrap a **second `StreamController` inside** the guard whose `onCancel` fires the side effect — fire-and-forget so slow observers can't stall the budget. The pattern `StreamController + watchdog Timer + cancel-correct teardown` recurs across 4.3 / 4.4 / 4.6 / 4.9 → **house pattern worth documenting (Action Item #3).**

### Challenge 4 (carried watch) — analyzer-12 stopgap (unchanged)
`freezed 3.2.6-dev.1` + asp + analyzer-12 pin still holds. 4.6 added `freezed` to `koel_http` for `TraceEntry` with the **exact** pin (explicitly not bumped — a stable freezed would break the workspace analyzer pin, SCP-2026-05-29-B). No reconciliation event yet; standing watch (Action Item #1). Tracked in project memory *Lint pivot: custom_lint → analysis_server_plugin*.

## Significant Discovery — affects Epic 5 plan

**🚨 Discovery 1 (resolved in-story, no planning-review needed):** Story 4.2's code review deferred —
> *"`_client`/`_interceptors` are library-private — Epic-5 cross-package subclasses (`AgnoAgent`/`LangGraphAgent`) cannot reach the transport seam (`_`-privacy is library-scoped; Dart has no `protected`). Revisit the extension surface when those backends land."*

But Epic 5 Story **5.1** (`class AgnoAgent extends HttpAgent`) and **5.4** (`LangGraphAgent extends HttpAgent`) assume inheritable access to the transport seam that 4.2 deliberately closed behind `_`-privacy. This is a plan assumption Epic 4 proved wrong-at-current-state.

**Project Lead decision:** Resolve as the **first task of Story 5.1** — a spike + a `@protected`/`@visibleForOverriding` (or constructor-seam) extension surface on `HttpAgent`, validated *before* AgnoAgent logic. Small enough to handle in-story; **no separate planning-review session required.** (`CopilotRuntimeAgent`, 5.8, sidesteps this entirely — it `implements AbstractAgent` directly with no koel_http dep per D5.)

**Discovery 2 (anticipated, on-trigger):** The "corrupt-line → `FormatException`" deferral cluster (3.3 `fixture_loader.dart:146`, 3.5 `conformance_runner.dart` `_loadExpectedCorpus`) has its documented revisit trigger as *"Epic 5 live captures can produce partial/truncated lines."* Epic 5 is that trigger. → fold an envelope-shape guard throwing a fixture-naming `FormatException` into the Epic-5 fixture/capture work.

**Discovery 3 (anticipated, partially ready):** Error-classification deferrals converge on Epic 5 adapters:
- 4.5 deferred *401→`businessAuth` HTTP-status classification* to Epic 5.
- 2.3 deferred the `DefaultErrorClassifier` *subclass-name asymmetry + private-impl-name → `unknown`* regression to "Epic 4/5 adapter subclasses."
- **Ready:** `AuthInterceptor` is `class` (not `final`) — built for `AgnoAuthInterceptor extends AuthInterceptor` (5.2). The auth seam is in place; only the error-classifier subclasses (5.2/5.6/5.9) carry the deferred work.

**Net: no Epic 5 plan rewrite required.** Discovery 1 is handled inside Story 5.1; Discoveries 2 & 3 are pre-scoped deferrals whose trigger is now active. No alignment session needed before Epic 5 kickoff.
