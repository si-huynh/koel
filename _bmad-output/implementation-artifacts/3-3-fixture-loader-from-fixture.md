# Story 3.3: `FixtureLoader` + `MockAgent.fromFixture(name)`

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

> **Dev agent:** this story writes the **first `koel_core` change of Epic 3** — and that is the whole story. It reads 3.2's bundled JSONL fixtures, **decodes each `payload` into a typed `AgUiEvent`**, and exposes `MockAgent.fromFixture(name)` so a test reduces to one line. Stories 3.1 and 3.2 were proudly *"zero `koel_core` change"*; this one **cannot** be — and that is correct, not scope creep (see trap #1). It touches `.dart` files, designs a new public API on a sealed freezed root, and resolves a package asset URI in a pure-Dart package. **Invoke `/agent-flutter-engineer` before producing any code** (per CLAUDE.md). Five things are load-bearing, and four are *non-obvious traps*:
> 1. **The codec is internal — you MUST cross the wall 3.2 deferred to you, by adding ONE public seam to `koel_core`.** `deserializeAgUiEvent(Map<String,dynamic>) → AgUiEvent` and `eventTypeRegistry` live in `koel_core/lib/src/event/event_deserializer.dart` and are **deliberately not exported** (`koel_core.dart:30-33` says so verbatim). `koel_test` imports **only the public barrel** (barrel discipline, 3.1/3.2) and convention forbids importing `package:koel_core/src/...` (architecture §6 :685). So the *only* legal way to decode a fixture `payload` is to **expose a public decode API from `koel_core`**. Do this as a static method `AgUiEvent.fromWire(Map<String, dynamic> json)` delegating to the existing internal `deserializeAgUiEvent` — keep the top-level function and the registry **internal**. See §"Crossing the codec wall". **This is the single biggest decision and it is RESOLVED below — do not re-litigate it, implement it.**
> 2. **`koel_test` is PURE DART — no Flutter SDK, no `rootBundle`.** AC1 names both `rootBundle.loadString` *(Flutter)* and `File`-relative *(Dart)*; only the **Dart arm** applies (3.2 was emphatic: do **not** add a `flutter:`/`flutter.assets:` stanza or Flutter dep — that would regress a framework-free package). Resolve the bundled asset with **`Isolate.resolvePackageUri('package:koel_test/src/fixtures/<subdir>/<name>.jsonl')`** (`dart:isolate`) → `File` → async read. This is what makes D8's *"reads via `package:` asset URI"* real **and** makes `fromFixture` work from *any* consuming package's test CWD (the "zero setup" promise — Epic 4 `koel_http` will load these fixtures). A bare `File('lib/src/fixtures/...')` only works when CWD == `koel_test`'s root and **breaks for downstream consumers** — do not ship that. See §"Resolving the package asset (no rootBundle)".
> 3. **Decode `line['payload']`, NOT the line.** Every event line is `{type, timestamp, payload}` where `payload` is the full wire object (it carries its own `type`) and the top-level `type` is a human-readable *mirror*. `deserializeAgUiEvent` consumes the **`payload`**. Passing the whole line (with `timestamp`) would corrupt the decode. The first line is the `_session` header — parse it into `FixtureSession` and **discard it from the event list** (AC1). See §"The on-disk fixture format".
> 4. **Unknown fixture name → `ArgumentError`, NOT `KoelError`.** This is the one place this code throws, and it is a **programmer error** (a typo'd fixture name), so it is `ArgumentError` with the **available fixture names enumerated** in the message — not the in-band `RunErrorEvent`/`KoelError` adapter channel (that rule is for *runtime* failures; a missing fixture is a *test-authoring* mistake). See §"Error contract". 
> 5. **Determinism + verbatim replay carry over.** The fixtures are byte-identical across machines (3.2); `fromFixture` builds a `MockAgent` whose `run(input)` replays them verbatim (3.1) — `input` is ignored, the fixture's own ids are the contract. AC2's `chatSession.state.messages.last.content == 'Hello, world!'` passes *because* `text_only_run.jsonl` is a self-consistent run bracket with non-empty `messageId`s. See §"Verbatim replay through the real pipeline".

## Dev Notes

### What this story is, in one paragraph
The **load-and-decode seam** of `koel_test`. 3.2 shipped the fixtures as JSONL data; 3.1 shipped `MockAgent`. This story connects them: `FixtureLoader` reads a bundled `.jsonl` (resolving its `package:` URI in pure Dart), parses the `_session` header into a typed `FixtureSession`, decodes each event line's `payload` into a typed `AgUiEvent`, and returns the event list — and `MockAgent.fromFixture(name)` wraps that into a one-line, zero-setup test double. The **one hard problem** is decoding: the wire deserializer is internal to `koel_core` and unreachable across the barrel, so 3.3 adds the **first `koel_core` change of Epic 3** — a single public `AgUiEvent.fromWire` seam (the architected fixture-decode entry per D8). Scope is exactly: the `koel_core` decode seam (+ its test), `FixtureLoader` + `FixtureSession`, `MockAgent.fromFixture`, the barrel export, and one `koel_test` test. **Not** `ConformanceRunner`/`ToolHandlerTestHarness`/coverage gate (3.4/3.5). [Source: epic-3 3.3 :54-75; D8 :371-383; 3.2 deferral note]

### Crossing the codec wall (the heart of this story) — RESOLVED
3.2 wrote it down explicitly: *"3.3 will have to decide how `FixtureLoader` reaches deserialization (a new public `koel_core` API, or some other seam). Do not pre-solve 3.3's codec-access problem."* Here is the resolution and the reasoning, so the dev implements rather than re-decides:
- **The constraint:** `deserializeAgUiEvent`/`eventTypeRegistry` are internal (`koel_core.dart:30-33` documents the intent). `koel_test` may import **only** the public barrel (3.1/3.2 barrel discipline; architecture §6 :685 forbids external `src/` imports). Events are freezed with private constructors — the registry deserializer is the *only* construction path from wire JSON. **Therefore decoding fixtures is impossible without a public `koel_core` seam.** There is no "other seam" that respects the conventions; the deferred decision resolves to **add the public API**.
- **The shape:** a static method `AgUiEvent.fromWire(Map<String, dynamic> json) => deserializeAgUiEvent(json)` on the sealed root. Why this and not a bare top-level export: (a) it is the **dual of the already-public `toJson()`** — symmetric, discoverable, idiomatic; (b) it is **namespaced** under `AgUiEvent`, so the registry and the top-level function stay internal (minimal surface widening — exactly one new public symbol); (c) it does not invite app code to hand-decode arbitrary streams (the barrel-comment concern) the way a bare `deserializeAgUiEvent` export might — `AgUiEvent.fromWire` reads as "reconstruct an event from its stored wire form," which is precisely the fixture/replay use case. The barrel comment at `:30-33` is reworded so it no longer claims the deserializer is wholly internal.
- **Totality:** `deserializeAgUiEvent` never throws (unknown `type` → `Unknown` subtype), so `fromWire` is total — the loader never needs a `try/catch` around decode; corrupt *JSON* (not corrupt *type*) surfaces as a `FormatException` from `jsonDecode`, which is the right loud failure for a corrupt fixture. [Source: event_deserializer.dart; 3.2 §"all 58 payloads decode through the real codec"]
- **This is sanctioned, not scope creep.** D8 architected `FixtureLoader` to decode bundled traces; the conformance pipeline (3.5) depends on it; barrel discipline forces the public seam. Justify it in the PR (architecture :698). [Source: D8; architecture :698; epic-3 3.5]

### The on-disk fixture format (what you are reading) — from 3.2
Each `synthesized/*.jsonl` is newline-delimited JSON, no enclosing array, no blank lines:
- **Line 0 — `_session` header**, a single top-level `_session` key:
  ```jsonl
  {"_session":{"koelVersion":"0.0.1","adapter":"synthesized","captured":"2026-05-26T00:00:00.000Z","threadId":"synth-text-only-run","runId":"synth-text-only-run-1","synthesized":true}}
  ```
- **Lines 1..N — event lines**, shape `{type, timestamp, payload}` where `payload` is the **full wire object** (carries its own `type`) and top-level `type` mirrors `payload.type`:
  ```jsonl
  {"type":"TEXT_MESSAGE_CONTENT","timestamp":"2026-05-26T00:00:00.200Z","payload":{"type":"TEXT_MESSAGE_CONTENT","messageId":"msg-1","delta":"Hello, world!"}}
  ```
**Decode `line['payload']`** (trap #3). The full `text_only_run.jsonl` (AC2's fixture) is `RUN_STARTED → TEXT_MESSAGE_START(msg-1) → TEXT_MESSAGE_CONTENT(msg-1,"Hello, world!") → TEXT_MESSAGE_END(msg-1) → RUN_FINISHED`, header/run-bracket sharing `synth-text-only-run`/`synth-text-only-run-1`. Replayed through the reducer (2.12), `messages.last.content == 'Hello, world!'` (AC2). [Source: 3.2 Task 2/3; subagent §C example fixture]

### Design decisions (RESOLVED — AC/architecture-forced, not open)
Baked in so the dev has zero ambiguity. No confirmation gate.
1. **Decode via a new public `koel_core` seam: `static AgUiEvent fromWire(Map<String,dynamic> json)`** on the plain `sealed class AgUiEvent` root, delegating to the internal `deserializeAgUiEvent`. Registry + top-level function stay internal; one new public symbol. This is the architected fixture-decode entry (D8) and the only barrel-discipline-respecting way to decode — 3.2's deferred decision resolves here. Implementation note: requires a mutual `ag_ui_event.dart ↔ event_deserializer.dart` library import (legal). Fallback (if the cycle is objectionable): `export 'src/event/event_deserializer.dart' show deserializeAgUiEvent;` from the barrel.
2. **Pure-Dart asset resolution via `Isolate.resolvePackageUri('package:koel_test/src/fixtures/...')`** — NOT `rootBundle` (no Flutter dep) and NOT CWD-relative `File('lib/...')` (breaks for downstream consumers). This realizes D8's `package:` URI and the "zero setup" cross-package promise.
3. **Decode `line['payload']`, not the line**; the `_session` header (line 0) parses to `FixtureSession` and is **excluded** from the returned event list (AC1).
4. **`FixtureSession` is a plain `final class`** (six header fields, `const` ctor, `fromJson`) — no freezed, no new dep. 3.5 owns any future codegen.
5. **Exactly four AC-named loaders** (`loadSynthesized`/`loadDojo`/`loadAgno`/`loadLangGraph`, signatures verbatim including `loadDojo(eventType)`) over a shared private `_load(subdir, name)`. **No `loadCopilotkitRuntime`** (not in AC).
6. **`MockAgent.fromFixture` is `static Future<MockAgent>`** (not a `factory` — Dart factories can't return a Future), targeting `synthesized/`, delegating to `fromEvents`.
7. **Unknown fixture → `ArgumentError`** (not `KoelError`) with disk-discovered available `*.jsonl` names enumerated; async throw asserted with `throwsArgumentError` on the future. `.placeholder` never listed as a fixture.
8. **Verbatim replay unchanged** — `fromFixture` reuses `MockAgent.fromEvents`; `run(input)` ignores `input`; AC2 passes because 3.2's fixtures are self-consistent with non-empty ids.
9. **No new dependency anywhere**; only SDK libs + the one `koel_core` method. No Flutter, no freezed, no `flutter.assets:` stanza.
10. **Package-finalization gates (doc/coverage) are Story 3.5, not 3.3.** 3.3 needs only `analyze`/`test`/`format:check` green.
