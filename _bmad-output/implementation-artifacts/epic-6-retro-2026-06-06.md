## What Went Well

1. **"A.6 is illustrative shorthand; the faithful source-true choice wins" became the house rhythm.** The same disciplined call repeated with evidence across the epic: 6.1 dropped the controller's `tools` param, 6.2 omitted `maybeOf`, 6.3 added no `open` factory, 6.4 added no `clearAll`, 6.5 used `final class` + no inline-code segment. Conversely, where the spec was *wrong* the story *added/substituted* with source evidence — 6.6 typed the resolver over `ToolCallStartEvent` (A.6's `ToolCallEvent` does not exist in koel_core) and shipped the epic-mandated `UnknownGenerativeUI` A.6 omitted. **Surface discipline is the epic's largest asset** — the public API was designed for what users *can't* misuse, not what A.6 happened to over-list.

2. **Sibling-template sequencing reduced risk and accelerated.** 6.4 (`SecureSessionStorage`) is a structural mirror of 6.3 (`HiveSessionStorage`) — same JSON codec, same four-method `SessionStorage` contract, same dartdoc voice; the only real deltas were the backing store and the namespace-prefix enumeration (D3). 6.8 is the koel_flutter twin of koel_core's 2.15 sealer. Diff-the-prior-sealer kept the surface and the gate routine consistent.

3. **Evidence-gated deferral, never fabrication.** 6.7 discovered `integration_test` cannot run on `flutter_tester` (a library package has no platform folders) — pivoted to plain `flutter_test` + `--platform chrome` with a local repro and Si's approval, recorded in `deferred-work.md`. 6.8 *verified* `dart_apitool 0.23.1` extracts a Flutter package on SDK 3.12 (a flagged unknown) rather than assuming. Same "Confirmed needs adversarial evidence" discipline as Epic 5.

4. **Dogfooding the lint.** 6.5 made `MessageSegment` (forward-declared in Story 1.7's `_sealedNames`) real, so `exhaustive_switch_must_have_default` went live workspace-wide — and an integration test (mirroring `dart_analyze_fires_test.dart`) proves it fires. koel eats its own dog food.

5. **First-epic-clean prior-retro follow-through.** For the first time in the retro series, **all six Epic-5 critical-path items (AI-5.1…5.6) closed before 6.1 started** (commit 70b89f8), and the two carried doc/watch items landed where promised (AI-5.8 → `docs/patterns/stream-cancellation.md`, used directly in 6.1; AI-5.9 held). Si's Epic-5 "close-now, don't accumulate to Epic 9" decision has become a durable habit — **the team's chosen #1 takeaway of the epic.**

## Challenges / Recurring Patterns

1. **Spec-reality gaps are real design weight, not "code the AC."** Every story 6.3–6.8 opened a "Context & scope (read first)" section resolving 1–3 traps the epic AC didn't name: 6.3 (no `isComplete` field exists → structural `pendingMessage` marker), 6.4 (flat single-namespace secure store → reserved key prefix), 6.6 (`ToolCallEvent` doesn't exist → `ToolCallStartEvent`), 6.7 (`integration_test` premise false), 6.8 (`flutter_tester` has no GPU raster → synchronous-work proxy). This is the **Flutter-layer recurrence of Epic 5's pattern** — the epic prose was written speculatively and each story had to reconcile it against framework/source truth.

2. **Bugs hidden behind "green-but-blind" tests.** 6.5's CRLF bug: the 500-string property suite gave false confidence because its generator *never emitted `\r`* — the highest-risk input was the blind spot. 6.8's jank-bench first draft read `pendingMessage` pre-settle and tripped at 0 (the final pump delivers the last delta *and* `TextMessageEnd`/`RunFinished` together). Both surfaced only under adversarial review — a reminder that a passing suite proves the cases it generates, not the cases it forgot.

3. **AC-vs-as-shipped divergence (Si-approved, not debt).** 6.7 shipped a plain `flutter_test` smoke (4 real lanes: macOS/Linux/Windows host + web Chrome) instead of AC2/D3/D5's `integration_test` device matrix; iOS/Android device lanes deferred to Epic 9/AR-17. A deliberate, source-evidenced deviation — recorded as a closed decision in `deferred-work.md`, not an open item.

## Key Takeaways

1. **Close-now debt is now a house habit** (Si's chosen #1 win). For the first time, every critical-path action item of the prior epic closed before this one started — the discipline Si converted from `deferred-work.md` at Epic 5 held through Epic 6 and is the pattern to keep.
2. **A.6 is illustrative; framework/source truth is canonical.** Trim over-listed surface, add/substitute where the spec names a non-existent type — every call backed by source evidence (6.1–6.6). This *is* the parity DNA, applied at the Flutter API boundary.
3. **Green-but-blind tests are the real risk at a new layer.** The CRLF bug (6.5) and the jank-bench-0 (6.8) both passed the suite that forgot their case; adversarial review caught both. Generators must cover the highest-risk inputs (`\r`, settle timing), or the suite is confidence theatre.
4. **Latents become live at the next package.** The 6.1 test_package.sh deferral and the Epic-1 flutter_lints drop were dormant only because `koel_flutter` was the sole Flutter package — `koel_widgets` (Epic 7) triggers both. Surface them as kickoff prep, don't let them ambush 7.2.
5. **An action item can be closed better than its brief.** AI-5.7 ("document the lossy 7/28 bridge") was resolved by *removing* the bridge (5.11) and documenting the full 25/28 matrix + a historical note — the parity-truthful outcome, superseding the original instruction.
