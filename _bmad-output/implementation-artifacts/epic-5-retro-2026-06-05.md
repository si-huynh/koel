5. **Conformance is the truthful partition, not optimistic "zero failures."** Every adapter asserts the exact `{passed, failed}` sets by name. The 7/28 copilotkit surface is the most honest artifact of the epic (see below) — not hidden behind a green checkmark.

## The Central Challenge — "Mock LLM + 7/28: are we avoiding the real problem?" (Si)

Si's opening critique drove the whole retro. Answered with adversarial evidence, it splits into **two different problems** that were being bundled:

### (A) 7/28 copilotkit is the genuine protocol ceiling — NOT avoidance

Evidence from [copilotkit/CONTRACT.md](../../koel_backend/backends/copilotkit/CONTRACT.md): the selection set koel sends is **verbatim from `@copilotkit/runtime-client-gql@1.8.14`** — CopilotKit's own canonical client. That `generateCopilotResponse` mutation carries only **4 message-output shapes** (`TextMessageOutput`, `ActionExecutionMessageOutput`, `ResultMessageOutput`, `AgentStateMessageOutput`) → exactly **7 AG-UI types** `{TEXT_MESSAGE_START/CONTENT/END, TOOL_CALL_START/ARGS/END, STATE_SNAPSHOT}`.

The other **19 AG-UI types** (`RUN_*`, `STEP_*`, `THINKING_*`, `REASONING`, `MESSAGES_SNAPSHOT`, `STATE_DELTA`, `RAW`, `CUSTOM`, `ACTIVITY`, `*_CHUNK`…) **have no representation in CopilotKit's GraphQL protocol at all** — `eventsToGraphQLParts` `ArgumentError`s on them (`graphql_event_conversion.dart:362`). Plus `RUN_STARTED`/`RUN_FINISHED` are emitted with the drive's own ids (a documented id artifact). Net partition: **passed 7, failed 21**.

**Verdict (parity DNA):** koel is a faithful Dart port. Making copilotkit "28/28" would require *fabricating events CopilotKit never sends* — inventing a richer CopilotKit than CopilotKit. **That** would be the avoidance — of protocol truth. 7/28 is correct *by the project's own parity principle*. langgraph 25/28 is categorically different: it is a native-AG-UI passthrough (`extends HttpAgent`), the corpus rides through verbatim. **Action:** document copilotkit as a lossy 7-type bridge in README/dartdoc so users don't expect otherwise — `document, not fix`.

### (B) The real publish risk — genuine correctness debt + thin agno capture

Si is right that confidence-to-publish is not yet earned — but the reason is **not** 7/28. It is five **real** deferred items (not protocol ceilings) plus capture thinness:

| Real debt (not a ceiling) | Severity | Nature |
|---|---|---|
| `@defer` mid-stream **ordering violation** — `CopilotRuntimeAgent` emits `START → CONTENT → END → CONTENT…`, violating AG-UI order | **HIGH** | Confirmed live in 5.9, re-deferred. Real correctness bug. Fix = buffering reorder in 5.7's converter. |
| `Message` **epoch-sentinel timestamp** re-serializes as `1970-01-01T00:00:00Z` | **HIGH for 6.3** | `HiveSessionStorage` round-trips `ChatState` via freezed `toJson`; the fabricated timestamp gets persisted + reloaded. |
| **No connect/read timeout** on `CopilotRuntimeAgent` | MEDIUM | Stalled stream wedges run forever (`RUN_STARTED`, no `RUN_ERROR`) → Epic-6 controllers leave `isStreaming==true` forever. |
| `ResultMessageOutput` **forward mapping wire-unverified** | MEDIUM | Tool-result path not proven against real wire. |
| **Silent truncation** — multipart stream missing `-----` terminator completes as clean `RUN_FINISHED` | LOW–MED | No completeness assertion. |

### The mock-LLM finding (answers Si's "local model or API?")

The three backends are **not the same story**, and "mock LLM" is a misnomer for two of them:

- **langgraph** ([graph.py](../../koel_backend/backends/langgraph/graph.py)) and **copilotkit** ([scripted-agent](../../koel_backend/backends/copilotkit/)) are **scripted — no LLM in the loop at all**. This is deliberate (NFR-3): deterministic conformance fixtures *require* deterministic output; a real LLM (local or API) is non-deterministic and would break fixture stability. Their coverage is a function of script richness — langgraph already covers 5 scenarios (6 fixtures), copilotkit covers text/tool/state (3).
- **agno** ([app.py](../../koel_backend/backends/agno/app.py)) runs the **real agno `Agent` + `OpenAIChat`**, pointed at a deterministic OpenAI-compatible **mock-llm** (`MOCK_LLM_BASE_URL=http://mock-llm:5555/v1`). The mock emits text only → that is *why* agno has just **1** real fixture. The adapter logic is fully exercised (the 25/28 synthesized corpus walks every type through the inherited SSE path), but the real agno framework's tool-call/state mapping has never been *witnessed* end-to-end.

**Research answer — local model vs API:** because agno hides its model behind the **OpenAI protocol**, pointing `MOCK_LLM_BASE_URL` at a **local Ollama / LM Studio** (`http://localhost:11434/v1`) is a **zero-code, keyless, offline** swap. A real local model makes agno emit genuine tool-call/state events via its native `run_agent` mapping — exactly the diversity the text-only mock lacks. **For langgraph/copilotkit a local model does not plug in** without rewriting the scripted glue (and would break determinism); they need scenario enrichment, not an LLM — and they are already the richest. **The real-LLM capture is therefore an agno-specific exploratory validation, kept OUT of the deterministic conformance corpus.**

## Recurring Patterns (cross-story synthesis)

- **`extends DefaultErrorClassifier` must delegate to the native inner classifier, not bare `super`** — the headline 5.2 finding, ported byte-identically into 5.6 and 5.9 (5.9's D5 twist: delegate to web-safe `DefaultErrorClassifier`, not koel_http-internal `transportErrorClassifier()`).
- **Trim/blank-guard auth secrets before the wire** — 5.2 (empty/whitespace token), 5.4 (whitespace apiKey, backported to the agno twin), 5.5 (threadId). A whole header-injection/padded-key family.
- **koel_core decode-kernel gaps only real wire exposes** — 5.6 (no-timestamp `MESSAGES_SNAPSHOT`), 5.9 (absent `content` on tool-call turns). Both were cross-cutting kernel fixes flagged outside the adapter package — a signal the pure-Dart kernel was under-exercised before real backends.
- **`format:check` red committed on `main` at 5.6**, caught + owned at 5.7 — validated Epic-4's auto-commit-on-done concern (memory: *own gate failures, no blame*).
- **Capture-tool id-normalization grew per backend** — `_normalizeMessageIds` (agno) → `_normalizeIds(fieldPrefixes)` (5.6) → `_normalizeUuids` deep walk (5.9). Each sealer found the prior normalizer insufficient.

## Key Takeaways

1. **7/28 is parity truth, not a gap.** A faithful port cannot conform to events the canonical protocol does not emit; documenting the lossy bridge is the correct response, fabricating events is not.
2. **"Mock LLM" is two different things** — scripted determinism (langgraph/copilotkit, by-design and correct) vs. thin agno capture (real framework behind a text-only mock). Only the latter is a real validation gap, and a **local Ollama swap fixes it cheaply for agno**.
3. **Real publish confidence = an explicit adversarial gate over named debt**, not trust in accumulated green. Si converted five deferred items from `deferred-work.md` into a close-now critical path.
4. **The kernel was under-exercised before real wire.** Two koel_core decode fixes (timestamp, content) only surfaced from live backend data — Epic 6's persistence layer is the first to round-trip them, so AI-5.2 must land first.
5. **Epic-4 AI#3 (cancel-teardown doc) re-carried a second time** — now directly on Epic 6's 6.1 path; close it this time.
