## Challenges & Patterns

### Challenge 1 — The "corrupt input → opaque `TypeError`" deferral cluster (consciously managed)
The same finding class recurred across three stories: a malformed/hand-edited fixture line surfacing a raw `TypeError`/`FormatException` with no line context.
- **3.2:** cast guards on non-object JSON — **fixed** (test-side).
- **3.3:** corrupt event line (missing/non-`Map` `payload`) — **deferred** (`fixture_loader.dart:146`).
- **3.5:** corpus `as Map`/`as String`/`jsonDecode` — **deferred** (`conformance_runner.dart` `_loadExpectedCorpus`).

Resolution logic is identical and deliberate: for **controlled, shipped, tested assets**, a loud failure is acceptable (design-decision #7; the koel_core codec deliberately rejects defensive payload validation "for a guarantee real callers do not need"). The honest revisit trigger is **Epic 5 live captures**, which *can* emit partial/truncated lines. All three are in `deferred-work.md` — a managed cluster, not drift.

### Challenge 2 — A5 ⟷ Epic-2 AI#3 conflict (resolved this retro)
Epic 2's Action Item #3 tasked Story 3.1 with adding `MockAgent.empty` and re-pointing `cold_start_bench` off its `_EmptyAgent` inline double. Story 3.1 **descoped `.empty`** (its ACs never name it), so `cold_start_bench` still uses `_EmptyAgent` (verified: no `.empty` in `mock_agent.dart`; `cold_start_bench.dart:40,79` still `_EmptyAgent`).

This is a genuine conflict between two of our *own* agreements: **A5** ("inline-double until the consumer-story exists") says *don't* ship `.empty` with no real consumer; AI#3 wanted the debt closed. The dev chose A5. **Project Lead decision (this retro): option (b) — close AI#3 officially. A5 wins.** A 4-line `_EmptyAgent` in one internal perf bench is a cheap, blessed double; adding `.empty` to the public API to serve a single internal bench would violate "no vestigial surface." The broader inline-double debt (2.9/2.10/2.14/2.15) *is* closed now that a real `MockAgent` exists; the bench's double is intentionally retained, not debt.

### Challenge 3 — Carried watch: analyzer-12 stopgap (unchanged)
`freezed 3.2.6-dev.1` + asp + analyzer 12 pin still holds. 3.5 added `freezed` to `koel_test` with the **exact** pin (explicitly not bumped — a stable freezed would break the workspace analyzer pin, SCP-2026-05-29-B). No reconciliation event yet; standing watch (AI#1). Tracked in project memory *Lint pivot: custom_lint → analysis_server_plugin*.

The 3.3/3.5 `FormatException`-vs-`TypeError` discipline informs this but does not block it.

**Significant-discovery check: NONE.** Nothing in Epic 3 forces an Epic 4 rewrite. Epic 3 delivered every primitive Epic 4 depends on cleanly. No planning-review session required.
