## What Went Well

1. **Dependency discipline beat convenience at the golden boundary — the epic's largest engineering win.** 7.4 needed a golden harness. `golden_toolkit` is archived; `alchemist` pulls a transitive `analyzer` that risks the AI-5.9/AI-6.3 pin. The call: **native `matchesGoldenFile`, Linux-canonical bytes generated via Docker (`ghcr.io/cirruslabs/flutter:3.44.0`), `@Tags(['golden'])` + `--exclude-tags=perf,golden`** so cross-platform default runs and macOS coverage never false-fail. Zero new hosted dep; the pin held all four stories. This is the parity/pin DNA applied to tooling, not just API surface — and it is *why* the lock-step in Epic 9 stays clean.

2. **`null-KoelTheme` resilience became a load-bearing, factored pattern.** A bare `CupertinoApp` inserts a `CupertinoTheme`, not a Material `Theme`, so `Theme.of(context).extension<KoelTheme>()` is **null** under Cupertino. Both 7.2 (`MessageBubble`) and 7.3 (`ChatInput`/`FollowUpList`) must fall back. 7.3 extracted 7.2's private `_fallbackTheme` into a shared internal `resolveKoelTheme(context)` (rule-of-three: bubble + input + pills), refactored the bubble onto it, and kept **26 bubble tests as the regression guard**. The "Cupertino variant crashes in its own target app" bug was designed out.

3. **Spec-reality discipline held at the widget layer.** `ChatInput` is built on **`EditableText`, not Material `TextField`** — `TextField` asserts `MaterialLocalizations` + a Material ancestor that a bare `CupertinoApp` lacks, so it would *throw* (verified `cupertino/app.dart:528-531`, `material/text_field.dart:97,1205`). Enter-submit / Shift+Enter-newline is delivered by a `Shortcuts` widget **wrapping** the field (the only override that beats root `DefaultTextEditingShortcuts`, verified `default_text_editing_shortcuts.dart:329` + `editable_text.dart:716-742`). Same "AC names an illustrative mechanism; the source-true choice wins" rhythm as Epic 5/6.

4. **Second consecutive clean prior-retro follow-through.** Both Epic-6 critical-path items closed **before** 7.1: **AI-6.1** (flutter_lints+asp profile, `koel_lints/koel_flutter.yaml`, empirically validated under asp) and **AI-6.2** (test_package.sh flutter-detection anchor — `koel_widgets` auto-flipped to `flutter test` the moment 7.1 added `flutter_test`). **AI-6.3** (pin watch) held — and the golden-harness decision was *driven by* it. Zero outstanding prior-epic items at Epic 7's start, for the second epic running.

5. **Adversarial catches baked into tests, not just patched.** 7.1 caught that `Color.lerp(black, white, .5) == 0x808080` on Flutter ≥3.27 float channels (not the stale int-era `0x7f7f7f`) and used a version-stable exact pair; the `lerp` midpoint test now asserts **all 14** interpolated slots, so AC3 "blends every slot" is literal not sampled. 7.3 patched `onSubmit` to deliver **trimmed** content (it shipped raw, contradicting its own dartdoc + AC1) and added `assert(maxLines >= 1)` with a `throwsAssertionError` test.

## Challenges / Recurring Patterns

1. **"Defer-to-the-SEALER" is a risky destination when the SEALER carries an independent heavy lift.** 7.1 and 7.2 deliberately punted **polish** to 7.4 ("7.4 is the SEALER, owns layout polish + goldens"). But 7.4's own scope — building a **harness-less native golden** pipeline from scratch (Docker byte-gen, tag-gating, dart_apitool, coverage wiring, example) — absorbed all the oxygen. The seal *mechanics* shipped; the *polish* did not. Three items stayed **OPEN in `deferred-work.md` with no CLOSED note** until this retro:
   - **Bubble max-width cap + long-code horizontal scroll** (7.2 → 7.4): long prose stretches edge-to-edge (the role `Align` becomes a no-op); a long unbreakable code token clips. Visual/UX gap, not a crash — but the real downstream consumer is now **Epic 9's sample app** (six-platform pub.dev showcase) where edge-to-edge looks unfinished.
   - **`TextStyle.lerp` inherit-parity dartdoc note** (7.1 → "7.4 finalize"): never written.
   - **`codeText 'monospace'` ledger entry** was actually **closed at 7.2** (`fontFamilyFallback: ['Menlo','Courier']`) but never marked — `deferred-work.md` drifted from reality.

   *Systemic lesson (blameless):* when a story punts to a later story, the later story must carry the punt as an explicit, tracked AC — not an ambient expectation — or a heavy SEALER will silently crowd it out.

2. **Carry-forward ergonomics/hardening from 7.3 (by design, not debt):** no external `controller`/initial-text on `ChatInput` (consumer can't pre-fill/clear); `onSubmit` throwing leaves the field uncleared (re-submits stale text); `followUpGap` lerp is unclamped, so a `t`-overshoot animation curve reaches `SizedBox(width:)`'s `width >= 0` assert. All low-probability / v-next — recorded as watch items, correctly out of the AC surface.

3. **The Epic-6 retro's defect prediction landed exactly.** Epic 6 predicted "heaviest Epic-7 defect = golden / Cupertino raster." Reality: the entire complexity of 7.4 concentrated in the golden harness (no harness in-workspace → native + Docker + Linux-canonical + tag-gate). The new visual boundary drew the heaviest defect, for the Nth epic running — confirming the "new layer draws the heavy defect" pattern (Epic 4 = first I/O, Epic 6 = first Flutter, Epic 7 = first goldens).

## Key Takeaways

1. **Dependency discipline is a feature, not a tax.** Refusing `alchemist` for a harness-less native golden pipeline kept the AI-5.9 pin intact and the Epic-9 lock-step clean. The same instinct that trims API surface trims the dependency graph.
2. **A punt needs an owner in the receiving story.** "Defer-to-the-SEALER" failed quietly because the SEALER's heavy independent lift crowded out the polish it was assumed to absorb. Punts must land as tracked ACs in the receiving story, or they evaporate.
3. **Ledger hygiene is part of "done."** `codeText 'monospace'` was fixed at 7.2 but the ledger said open; the max-width cap was assumed done at 7.4 but was open. Closing/re-homing entries at the retro is how the deferred-work ledger stays a source of truth.
4. **The new-layer-draws-the-heavy-defect pattern is now predictable enough to staff.** Goldens were forecast as the heavy Epic-7 boundary and were. Forecast Epic 9's heavy boundary = the **publish/CI gate bodies** (six workflows green, dart_apitool diff, perf thresholds) and Epic 10's = the **`devtools_extensions` dep + iFrame postMessage boundary**.
5. **Clean prior-retro follow-through is now a two-epic habit.** Zero outstanding items at the start of both Epic 6 and Epic 7 — Si's "close-now debt" discipline is holding across the series.
