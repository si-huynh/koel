## 2026-05-28 — Reviewer-gate resolutions (4 critical decisions)

Six parallel subagents reviewed `prd.md` + `addendum.md`. Full reviews in workspace files: `reconcile-brief.md`, `reconcile-brainstorming.md`, `reconcile-spec.md`, `review-rubric.md`, `review-api-and-completeness.md`, `review-adversarial.md`. The four architectural one-way doors the parent could NOT auto-resolve were surfaced; user decisions follow.

### D-1 — Sealed `AgUiEvent` vs semver-minor-for-new-events

**Resolution:** Keep sealed `AgUiEvent`. Ship a new 10th package `koel_lints` that defines a mandatory lint rule (`exhaustive_switch_must_have_default`) targeting `switch` statements on `sealed AgUiEvent`. Adding a new event subtype remains a **minor** version bump because consumer code is required (via lint) to include a `default:` branch, so new subtypes do not break exhaustive switches.

**Why:** Best of both worlds — compile-time exhaustiveness when consumers want it (omit `// ignore: ...` + always have default), forward-compat-friendly semver minor bumps for AG-UI evolution. Costs one new package (`koel_lints`) and one new mandatory rule in koel's documented best-practice analyzer config.

**Implication:** Package count is now **10**, not 9. References across PRD and addendum updated. `koel_lints` is foundation-tier (lock-step with `koel_core` + `koel_http`).

### D-2 — `koel_runtime` scope

**Resolution:** Keep `koel_runtime` in v1 but reposition it as a **backend bridge**, not a "transport." SSE-over-HTTP via `koel_http` is the primary protocol transport. `koel_runtime` is a second-class adapter for consumers whose backend is the CopilotKit Next.js runtime (which speaks streaming GraphQL rather than direct AG-UI SSE).

**Why:** The cynical reviewer correctly noted that calling it a transport alongside SSE flattened a meaningful hierarchy. As a backend bridge it is a peer of `koel_agno` and `koel_langgraph` — same conformance contract, different wire shape.

**Implication:** F-G1 captured-fixtures source list grows from 3 backends (dojo + agno + langgraph) to **4** (dojo + agno + langgraph + CopilotKit Next.js runtime). Architecture table §7 updates: `koel_runtime` row layer changes from "Adapter" to "Adapter (backend bridge)."

### D-3 — Performance NFRs framing

**Resolution:** Drop absolute performance numbers (N-1 through N-4). Replace with **regression-relative SLOs** measured against a CI-tracked reference benchmark suite.

**Why:** Adversarial reviewer correctly flagged that "10k events/sec on Pixel 4a with `freezed` deserialization + reducer rebuilding 1000-element message lists per event" doesn't math arithmetically. Better to commit to "no regression > X% vs the reference benchmark" — honest, falsifiable, CI-enforceable, and lets actual numbers emerge from implementation. Absolute targets can be added in v1.x once real data exists.

### D-4 — `koel_flutter` coverage tier

**Resolution:** Restore brief commit — `koel_flutter` ≥ 90% line coverage alongside `koel_core` and `koel_http`. Other packages remain at ≥ 80%.

**Why:** Brief explicitly committed ≥90% for `koel_flutter` as part of the foundation tier (P1's primary touchpoint). Earlier draft silently downgraded to ≥80%. Correcting to brief baseline.
